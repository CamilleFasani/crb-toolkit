# P2C - From Palette to Canvas

## 1. Rôle
Créer un tableau impressionniste (petites touches de couleur) en SVG.

## 2. Modes
- **[Décidé]** Un seul mode, abstrait : palette seule → composition inventée.
- **[Écarté]** Mode figuratif (photo + palette → la photo repeinte en touches). La palette étant choisie à la main, l'autrice oriente l'outil vers l'abstrait.
- **[Piste]** Proportions des couleurs : réglage de P2C (et non mesure faite par P2P).

## 3. Sortie
- SVG, déclinable desktop et mobile (nombre de touches réduit).

## 4. Pistes
- **[Piste]** Graine aléatoire fixe → résultat reproductible.
- **[Piste]** Réglages : taille, densité, orientation, forme des touches.
- **[Piste]** Nombre de touches plafonné (performance web).
