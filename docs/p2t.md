# P2T - From Photo to Texture

## 1. Rôle
Extraire d'une photo une texture (contours, formes, variations d'opacité), utilisable sur le web.

## 2. Méthode
- **[Décidé]** Détection de contours + carte de luminosité (opacités). À tester.

## 3. Sortie
- **[Décidé]** SVG, léger.

## 4. Pistes
- **[Piste]** Simplification des tracés pour limiter le poids.
- **[Piste]** Texture monochrome, colorable en CSS (`currentColor`) ou utilisable en `mask-image`.
